Overview

WP Series worm gearboxes are cast-iron, right-angle speed reducers for industrial applications that need a robust shaft-mounted or flange-input drive arrangement. Select the final configuration by ratio, mounting orientation, shaft connection and required output torque.

Components

1. Housing: Cast iron.

2. Gearset: One-stage worm gear arrangement.

3. Input configurations: Solid input shaft or IEC B5 motor-flange input.

4. Output configurations: Solid output shaft or hollow output shaft.

Features

  • Different input and output shaft arrangements for horizontal or vertical installations.
  • Compact right-angle transmission layout.
  • Direct-drive or indirect-drive arrangements can be selected by the application.
  • Solid-shaft and hollow-shaft output options.

Selection Notes

Before ordering, confirm the motor power and speed, required ratio or output speed, required output torque, mounting position, input flange or shaft dimensions, and output connection. Frame size and ratio alone do not confirm suitability; thermal duty and service conditions must also be checked.

What is a BKM hypoid gearbox?

The SMK BKM series is a right-angle speed reducer using hypoid gearing. It is considered for conveyors, packaging lines, logistics equipment, mixers, food machinery and automation systems where compact installation and efficient continuous operation are important.

A hypoid reducer should not be selected from efficiency claims alone. The selected model must meet speed, mechanical torque, peak load, thermal duty, shaft-load and interface requirements.

Why consider hypoid instead of worm gearing?

  • Suitable for efficient right-angle power transmission
  • Lower operating heat than many conventional worm designs at comparable duty points
  • Compact installation for machinery layouts
  • Useful for frequent or continuous operation when correctly selected
  • IEC motor-ready and other input configurations subject to model confirmation

Actual performance depends on the selected frame, ratio, speed, load and lubrication. Compare the application using the NMRV versus hypoid gearbox guide.

NMRV SIZE 150 TECHNICAL GUIDE

NMRV150 Worm Gearbox

Dimensions, 50 mm output bore, ratios, motor-flange options and selection guide

Published September 23, 2026 · SMK Transmission technical guide

Quick answer: NMRV150, also called RV150, is a large aluminum right-angle worm reducer. The illustrated configuration uses a 50 mm hollow output bore and standard ratios from 7.5:1 to 100:1. Motor input bore and flange must be matched to the selected motor, ratio, output torque, thermal duty, service factor and mounting position.

NMRV150 Dimensions and Technical Reference

The NMRV150 worm gearbox is commonly considered for industrial drives that need a larger output shaft, a compact 90-degree layout and substantial speed reduction. The supplied drawing shows the principal installation interfaces for one configuration.

RV150 Output Bore: What Does 50 mm Mean?

A typical RV150 configuration uses a 50 mm hollow output bore. This is the gearbox output interface, not automatically the motor shaft diameter. For replacement work, compare the output shaft, keyway, tolerance, flange pilot, bolt pattern and mounting dimensions before ordering.

NMRV150 Ratios and Theoretical Output Speed

Common ratios include 7.5, 10, 15, 20, 25, 30, 40, 50, 60, 80 and 100:1.

Theoretical output speed = motor rated speed ÷ gearbox ratio

Example assumption: 1400 rpm motor with a 50:1 ratio.

1400 ÷ 50 = approximately 28 rpm

How to Select an NMRV150

Confirm motor power, rated speed, voltage and frequency; required continuous and peak torque; output rpm; operating hours; service factor; output shaft; motor flange; mounting position and application. The NMRV size guide from RV25 to RV150, conveyor gearbox selection page and service-factor guide provide useful checks.
